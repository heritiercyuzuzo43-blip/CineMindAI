# CineMind AI

CineMind AI is a machine learning project that predicts whether a movie is likely to become a Hit, Average, or Flop based on features such as genre, budget, runtime, release month, and popularity.

## Project Structure

- data/: datasets
- notebooks/: experiments
- models/: trained models
- src/: Python modules
- app/: Streamlit app
- reports/: generated reports

## Setup

1. Create and activate the virtual environment.
2. Install dependencies: pip install -r requirements.txt
3. Run the training script: python src/train_model.py
4. Launch the Streamlit app: streamlit run app/app.py
